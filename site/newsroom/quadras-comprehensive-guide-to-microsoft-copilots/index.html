Quadra’s Comprehensive Guide to Microsoft Copilots

Quadra’s Comprehensive Guide to Microsoft Copilots

Blog Summary

Microsoft's suite of Copilots leverages artificial intelligence to enhance productivity, creativity, and efficiency across its product stack. At Quadra, we created this guide to provide an overview of the various Copilots available, detailing their integration points, licensing requirements, and the benefits they offer.

Blog Details

General Purpose

Copilot

Product Availability: Integrated across Microsoft's suite of products and services.

Licensing: Generally available with Microsoft services.

Benefits: Offers conversational AI capabilities for general inquiries, content creation, and internet searches.

Includes: Chat with text, voice, and image capabilities, Summarization of documents and web pages, Image creation in Designer (formerly Bing Image Creator), Web grounding. Use of plugins and Copilot GPTs.

Copilot Pro

Product Availability: Microsoft 365 web apps for individuals.

Licensing: Licensed. Available as a monthly subscription.

Benefits: Provides priority access to AI models for faster performance, the ability to create custom Copilot GPTs, and enhanced AI image creation with Designer.

Includes: Everything in Copilot plus Faster responses during peak times, Copilot in select Microsoft 365 apps, and Faster AI image creation

Reference Links

Copilot vs Copilot Pro difference - Microsoft Copilot | Microsoft AI

Copilot for Windows

Product Availability: Windows 11.

Licensing: Part of the Windows 11 update, thus available to Windows 11 users without additional cost.

Benefits: Simplifies tasks and reduces cognitive load with AI-powered assistance.

Productivity

Copilot for Microsoft 365

Product Availability: Integrated across Microsoft 365 apps, including Word, Excel, PowerPoint, Outlook, and Teams.

Licensing: Licensed. Available for Business and Enterprise customers with Microsoft 365 subscriptions. Licensed per user per year

Benefits: Enhances productivity by automating repetitive tasks, generating content, and providing data analysis and insights.

Includes: Everything in Copilot plus Copilot in Word, Excel, PowerPoint, OneNote, and Outlook, Copilot in Microsoft Teams, Enterprise-grade data protection, Microsoft Graph grounding, Customization and extensibility through Microsoft Copilot Studio

Reference Links

Copilot for Microsoft 365

Security

Copilot for Security

Product Availability: Microsoft Security Solutions.

Licensing: Licensed. Requires specific Microsoft security solutions subscriptions.

Benefits: Enhances cybersecurity operations with AI-driven insights and automation.

Reference Links

Copilot for Security Pricing- Microsoft Copilot for Security - Pricing | Microsoft Azure

Copilot for Security Coverage and Capabilities- MSCP_Infographic_Whatcanitdo_v9 (microsoft.com)

Developer

Copilot Studio

Product Availability: Copilot for Microsoft 365 & Copilot Studio subscription

Licensing: Part of the Copilot for Microsoft 365 offering, thus requiring a relevant subscription. (Use rights with Copilot for Microsoft 365 licenses, Copilot Studio for Teams (Teams only) with selected M365 Licenses, Copilot Studio subscription (25,000 messages))

Benefits: Allows organizations to customize Copilot to their specific needs, integrating business data and automating processes.

Reference Links

For more Information about Copilot for Studio- Microsoft Copilot Studio overview - Microsoft Copilot Studio | Microsoft Learn

GitHub Copilot

Product Availability: GitHub Copilot is readily available for developers, providing an AI-powered coding companion that integrates seamlessly with your coding environment.

Licensing: GitHub Copilot is licensed under a monthly subscription model, offering full access to its AI capabilities and regular feature updates.

Benefits: GitHub Copilot offers real-timecode suggestions, accelerates coding tasks, and helps in writing better code by learning from your style and preferences. It also supports a wide range of programming languages and frameworks, enhancing developer productivity.

Includes: The subscription includes access to GitHub Copilot’s full suite of features, priority support, and advanced AI features that adapt to your unique coding style, ensuring a more personalized and efficient coding experience.

Role-Based

Copilot for Sales

Product Availability: Dynamics 365 for Sales.

Licensing: Licensed. Requires a Dynamics 365 Sales subscription. (Users who want to use Copilot for Sales need to be licensed users of Dynamics 365 Sales.)

‍Benefits: Streamlines sales processes by providing insights, generating content, and automating tasks.

Reference Links

Copilot in Dynamics 365 Sales overview - https://learn.microsoft.com/en-us/dynamics365/sales/copilot-overview

Copilot for Finance

Product Availability: Dynamics 365 Finance.

Licensing: Licensed. Requires a Dynamics 365 Finance subscription. (Users who want to use Copilot for Finance need to be licensed users of Dynamics 365 Finance.)

Benefits: Automates financial reporting and analysis, enhances budgeting processes, and provides real-time financial insights.

Reference links

Overview of Copilot in Finance and Operations apps - https://learn.microsoft.com/en-us/dynamics365/fin-ops-core/fin-ops/copilot/copilot-for-finance-operations

Copilot for Service

Product Availability: Dynamics 365 Customer Service.

Licensing: Licensed. (Dynamics 365 Customer Service Enterprise license for summarize cases, ask a question, draft emails, and copilot analytics features, Customer Service add-in (Chat, Digital Messaging, or Voice) license for draft a chat response and summarize conversations features.)

Benefits: Enhances customer service through automated responses, insights into customer queries, and streamlined service operations.

Reference links

Manage Copilot features in Customer Service - https://learn.microsoft.com/en-us/dynamics365/customer-service/administer/configure-copilot-features

Dynamics 365 Customer Service - https://dynamics.microsoft.com/en-us/customer-service/pricing/

Employee Experience

Copilot for Viva

Product Availability: Microsoft Viva.

Licensing: Licensed. Available as part of specific Viva subscriptions.

Benefits: Improves employee experience and engagement through personalized insights and recommendations.

Reference Links

https://www.microsoft.com/en-us/microsoft-365/blog/2023/04/20/introducing-copilot-in-microsoft-viva-a-new-way-to-boost-employee-engagement-and-performance/

Azure

Copilot for Azure

Product Availability: Azure Services.

Licensing: Licensed. Requires Azure subscription.

Benefits: Facilitates cloud management and development with AI-driven insights and automation.

Reference Links‍

https://learn.microsoft.com/en-us/azure/copilot/capabilities

Reporting and Visualization

Copilot for Power Platform

Product Availability: Power Platform.

Licensing: Licensed. Available with Power Platform subscriptions. (Copilot for Power Platform is available with Power Platform subscriptions, Requires a valid subscription to Power Platform services such as Power Apps, Power Automate, or Power BI, Each user who wants to use Copilot features must be licensed under the relevant Power Platform service.)

Benefits: ‍

a. Streamlined App Development: Provides AI-powered suggestions and automation to simplify app development within Power Apps. ‍

b. Enhanced Data Analysis: Offers advanced AI-driven insights and data analysis capabilities in Power BI. ‍

c. Automation of Processes: Automates workflows and repetitive tasks using AI in Power Automate, increasing efficiency.

Reference links

Licensing Guide - https://go.microsoft.com/fwlink/?linkid=2085130

Data Platform

Copilot for Cosmos DB (Copilot for Azure)

Product Availability: Azure Cosmos DB.

Licensing: Licensed. Requires Azure Cosmos DB subscription.

Benefits: Enhances database management and query optimization with AI-driven insights.

For more information, https://learn.microsoft.com/en-us/azure/copilot/capabilities

Copilot for SQL DB (Copilot for Azure)

Product Availability: Azure SQL Database.

Licensing: Licensed. Requires Azure SQL Database subscription.

Benefits: Automates database management tasks and provides performance tuning recommendations.

Copilot for Fabric (Copilot for Azure)

Product Availability: Azure OpenAI Service.

Benefits: Streamlines microservices development and deployment with AI-powered insights and automation.

Copilot for Real-Time Intelligence

Benefits: It is an advanced AI tool designed to help you explore your data and extract valuable insights. You can input questions about your data, which are then automatically translated into Kusto Query Language (KQL) queries. Copilot streamlines the process of analyzing data for both experienced KQL users and citizen data scientists.

For more information, https://learn.microsoft.com/en-us/fabric/get-started/copilot-real-time-analytics

Conclusion

This guide from Quadra aims to help users navigate the landscape of Microsoft Copilots, understanding where each can be applied, their cost, and how they can transform the way we work and interact with technology.

For more information, and to discover how to create positive business outcomes using AI, please contact Quadra. We’re here to help!
