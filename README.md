# QUADRA-WEBSITE

Local working copy of the Quadra website (quadrasystems.net) with the v0.5 content pack applied: the live site, copied
read-only, with every page in the content pack rebuilt in the live design and the new copy. This is the site that runs
on http://localhost:8081.

## Run it

Requires Node.js 18 or newer. No install step and no dependencies.

```bash
node serve_site.js 8081 live_updated,live_mirror
```

Then open http://localhost:8081. The port matters: the copied pages load their scripts, fonts and images from
`http://localhost:8081/_mirror/...`, so the site must be served on 8081.

The untouched copy of the live site (before the new content) can be served next to it for comparison:

```bash
node serve_site.js 8082 live_mirror
```

## Deploy (Vercel or any static host)

`vercel.json` tells Vercel to run `node build_deploy.js` and publish `dist/`. That script merges `live_updated/` over
`live_mirror/` into `dist/` and turns every `http://localhost:8081` address into a root-relative one, so the same
site works on any domain. Two things are left to Framer's public CDN through the rewrites in `vercel.json`, read-only
as the local server does: image sizes that were never saved locally (`/_img/...`) and the CMS data that Framer reads
in slices (`.framercms`). To try the static build locally: `node build_deploy.js`, then serve `dist/` with any
static server.

## What is in here

| Path | What it is |
| --- | --- |
| `live_updated/` | The site served on 8081: 67 pages rebuilt with the new content, plus the 237 other live pages unchanged. Generated by `build_live_copy.js`. |
| `live_mirror/` | Read-only copy of the published live site: every page plus its Framer scripts, images, videos and fonts. Generated by `mirror_live.js`. |
| `site_src/` | The pieces added to the rebuilt pages: `q.css` (styles), `q.js` (navigation, theme, hero fitting), `compass.js` (The Compass chat), `live_links.js`, and `logos/` (Quadra platform logos). |
| `content.json`, `navigation.json` | The v0.5 content pack: page copy, modules and navigation. |
| `live_extract/` | Text, links and images of each live page, extracted read-only. |
| `site/` | An earlier template-based build of the content (served on 8080 by `node serve_site.js`). |
| Review documents | `Quadra_Website_Review.html`, `LIVE_VS_LOCAL_COMPARISON.html`, `LIVE_PAGE_DECISIONS.csv` and the review and QA notes. |

## Rebuilding

| Step | Command | When |
| --- | --- | --- |
| Rebuild the 8081 site from the content pack | `node build_live_copy.js` | After editing `content.json`, `navigation.json` or anything in `site_src/` |
| Re-download the live site | `node mirror_live.js` | When the live site has changed (about 1.3 GB) |
| Re-extract live page text | `node extract_live.js` | When the live site's text has changed |
| Prepare product logos | `powershell -File prep_logos.ps1 -Project "<this folder>"` | When the logo files change (Windows) |

`build_live_copy.js` never writes to `live_mirror/`. Nothing in this project changes the Framer project or the live
site: both are only read.

## Notes

- The Compass on the rebuilt pages is a local preview: it answers with passages from this site's own pages and sends
  nothing anywhere. The live Compass service, analytics, Framer forms and EmailJS are disconnected in the copy.
- Light and dark themes follow the live site's theme switch (stored as `theme` in local storage).
- `MAINTENANCE.md` and `START_HERE.md` describe the content pack and its review process.
